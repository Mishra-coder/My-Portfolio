## 🎨 Key Features

- **Editorial Yellow-Green / Lime Palette**: Soothing `#fafbf7` off-white base with soft radiant lime glows and deep slate typography, completely gentle on the eyes.
- **3D Hero Stage & Studio Cutout**:
  - Transparent portrait cutout with natural silhouette drop-shadows.
  - Multi-layer 3D typography sandwiching the portrait (`Hi I'm Devendra` behind head, `Full Stack & AI Engineer` framing across face and hair).
  - Ambient radial glowing aura and live availability beacon.
- **Continuous Editorial Flow**:
  - Horizontal tech stack ticker marquee.
  - Featured Projects Showcase bar with clean 2x3 bento grid (Success Mantra, Karo Pitch, AKOIN, Zappify, Aroma Luxe, AI Background Remover).
  - Philosophy statement with capability tags.
  - 3-step process cards (*Discover*, *Design & Build*, *Deliver*).
  - Radiant "Let's Make It Happen" pre-footer CTA banner.
  - Giant signature footer.
- **Dedicated Profile Explorer Modal**:
  - Deep sections (*About Me*, *Projects*, *Skills*, *Achievements*, *Resume*, *Contact*) accessible directly via the Menu Bar.
  - Segmented tab bar with keyboard `ESC` and backdrop dismiss support.
  - Unified light-theme glass boxes and cards with interactive 3D orb.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, HTML5, Modern CSS3
- **3D / Visuals**: Three.js, Canvas Confetti
- **Icons**: Lucide React, Custom SVG Icons
- **State & Utilities**: Custom hooks (`useTilt`), responsive drawer navigation

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
